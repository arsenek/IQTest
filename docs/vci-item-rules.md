# VCI 规则生成题 · 审核摘要

本文件由规则生成管线维护（`npm run vci:generate`）。正式包与练习包的 VCI 题均来自闭集词典上的声明式规格，程序断言唯一正解。

## 题型

| 题型 | 规则 | 唯一解条件 |
|------|------|------------|
| 分类 classify | 闭集范畴成员 | exemplars 与正解 ∈ 范畴；干扰项 ∉ 范畴 |
| 序列 sequence | 等差数字或有序循环 | 递推下一项唯一；干扰项 ≠ 该项 |
| 类比 analogy | 闭集二元关系 R | R(A,B)∧R(C,正解)；干扰项均 ¬R(C,·) |

**不做：** 开放域「选词义」词汇题（无法在无大型词典下形式证明唯一解）。原 `*-vci-vocab` 分测验现为分类+序列，ID 保持不变。

## 结构

| 包 | 分测验 | 题量 |
|----|--------|------|
| child/v1 | child-vci-vocab / child-vci-analogy | 16 + 7 |
| adult/v1 | adult-vci-vocab / adult-vci-analogy | 16 + 7 |
| */practice/v1 | *-prac-vci | 10 |

## 规则族一览

- **儿童分类：** 水果、动物、交通工具、家具、学习用品、天气、身体部位、颜色、职业、地理
- **成人分类：** 科学方法、逻辑词、经济学、修辞、地理、职业（偏抽象）
- **序列：** 等差（1/2/3/5/7/…）与天干、四季、地支、五声、五行等循环
- **类比：** 栖息地、工作场所、工具对象、部分—整体、反义、范畴成员、因果、程度

## 样例

**child-vci-1（分类）**  
题干：看看「苹果、香蕉、橙子」。下面哪一项和它们是同一类？  
规则：同属「水果」。正解：葡萄。

**child-vci2-1（类比）**  
题干：「鸟」对「天空」，就像「鱼」对？  
规则：栖息地。正解：水。

**adult-vci-11（序列）**  
题干：根据序列规律，下一项应为？ 3、6、9、12、？  
规则：每次加 3。正解：15。
